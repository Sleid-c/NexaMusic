# NexaMusic

Лёгкий музыкальный плеер (PWA): ищите открытую музыку, скачивайте её прямо в приложении и слушайте без интернета.

## Возможности
- Поиск по открытым источникам: **Internet Archive** (только лицензии Creative Commons) и **Jamendo** (нужен бесплатный client_id).
- Кнопка «Скачать» сохраняет трек в память браузера (IndexedDB), он играет офлайн.
- Свои файлы тоже можно добавить в библиотеку.
- Плеер: перемотка, перемешивание, повтор, управление с экрана блокировки.
- Устанавливается на телефон или компьютер как приложение, работает без сети.

## Запуск на GitHub Pages
1. Создайте репозиторий `NexaMusic` и загрузите все файлы из этой папки в корень.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Откройте `https://ВАШ-НИК.github.io/NexaMusic/`.
4. Установите: «Добавить на главный экран» (телефон) или значок установки в адресной строке (компьютер).

Локально: `python -m http.server 8000`, затем http://localhost:8000.

## Jamendo
Зарегистрируйтесь на devportal.jamendo.com, создайте приложение, вставьте client_id во вкладке «Настройки».

## Лицензии
Проверяйте лицензию каждого трека (она показана в списке). CC-BY, CC-BY-SA и другие требуют указания автора, а часть лицензий запрещает коммерческое использование.
Приложение не получает музыку из Spotify, YouTube и других закрытых сервисов.

## Идеи для развития
